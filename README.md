# Vytal · Landing del QR

Landing de alto impacto a la que lleva el QR de la lata de Vytal (Lima Limón, 354 ml).
Sitio estático: `index.html` + `assets/`. No necesita build.

## Publicar en GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
La URL resultante (`https://<usuario>.github.io/<repo>/`) es la que va en el QR.
